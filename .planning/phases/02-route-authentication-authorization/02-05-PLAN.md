Router recipe (`resources/weight.py` after plan 02-04 is the reference): import `Access, authorize` from `..authz.engine` and drop imports left unused; put `access: Access = Depends(authorize("<module>", "<op>"))` on all seven handlers with ops create, get, patch, delete, undelete, purge, list; pass `access` into `_fetch` and end it with `return access.check_record(check_parent(...))`; create with `access.stamp_create(body.model_dump(exclude_unset=False), parent_id=user)`; patch with `apply_patch(entity, body, principal=access.principal)`; list with `items = access.scope_list(repo.get_for_owner_between(user, rng.start, rng.end))` before `paginate`.

A throwaway script may apply the recipe; do not commit it. Read each resulting diff. Do not edit `tests/test_policy_matrix.py` or `authz/engine.py`: four other plans run beside this one, and `ROLLED_OUT` detects a router on its own. If the engine appears wrong, stop and report it rather than editing it here.

Facts verified by the planner against the current tree:
- `goal.py` builds entities in `_build_goal(body, user, principal)` through `stamp_audit`, and lists through `repo.get_all_for_owner_between` or, with a kind filter, `repo.get_all_for_owner_by_kind_between(..., kind=parsed["kind"])`. `LegacyGoal` has no `kind` attribute, so filter through the repository method, not in Python.
- `_FILTERABLE = {"kind": int}` in `goal.py` is the only field a filter can name, and `parse_filter` answers 400 for anything else.
- `test_goals_carveout.py` creates under `u-1`, `u-2` and `u-3` with no Participant, and sends `X-Principal-Id`. Study binding needs a Participant for each owner, and the header is now meaningless.
- `get_for_owner_between` is missing from the Couchbase adapters of `asset`, `card`, `meta_data`, `physical_activity`, `post`, `session`, `survey_result`, `user_sleep` and `user_stress` (probed against `RepositoryContainer`), so those lists raise 500 on a live store. That predates this phase; in-memory fakes have the method, so this plan's tests pass regardless. It is reported to the developer and out of this plan's scope.
