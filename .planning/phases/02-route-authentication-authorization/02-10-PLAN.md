Facts verified by the planner against the current tree:
- `create_app` is `def create_app() -> FastAPI` with `settings = APISettings()` and `FastAPI(title=settings.title, lifespan=lifespan)`; `app = create_app()` at module level must stay.
- Probe: `docs_url=None, redoc_url=None` alone still serves `/openapi.json`; all three of `docs_url`, `redoc_url` and `openapi_url` must be None. With them None, `app.routes` holds only `APIRoute` entries.
- Today's route table has 265 entries: 254 non-exempt method-and-path pairs under `/v1`, 6 auth, `/healthz` and 4 docs routes (`/openapi.json`, `/docs`, `/docs/oauth2-redirect`, `/redoc`). Build times are about 0.35 s per app, so share one module-scoped app.
- `route.dependant.dependencies` lists a route's dependencies, each with `.call`; a callable-class instance appears as the instance, so `isinstance(dep.call, authorize)` works.
- The floor is `openwellness_api.v1.FloorRoute` from plan 02-03, a route class and not a dependency, so `isinstance(route, FloorRoute)` identifies a floored route. Probe of that mechanism against today's table: 254 pairs, 0 non-401 for an anonymous body of `{` with `Content-Type: application/json`.
- `OpenWellnessSettings` loads `<repo root>/.env` through `resolve_env_file()`, and `APISettings` inherits that. Probed with a temporary env file: `APISettings()` reads a value from it, `APISettings(_env_file=None)` does not, and an init kwarg beats both. So a developer's local `.env` with `API_ENABLE_DOCS=true` would flip a bare `APISettings()`. `build_test_app`'s explicit `enable_docs=False` is safe.
- `conftest.build_test_app` still builds a bare `FastAPI` plus `register_exception_handlers` and `build_v1_router`, so today's tests would not see `/healthz` or the docs settings.
- `body_for(module)` in `tests/test_policy_matrix.py` builds a valid create body; `tests` is a package, so `from .test_policy_matrix import body_for` works and pytest does not collect it.
- `backend/api/README.md` describes the fallback header and the removed setting in the `deps/` bullet and in the settings paragraph.
- `.env.example` has no `API_` docs entry; baseline `grep -c '^API_ENABLE_DOCS' .env.example` is 0.
