<objective>
Make repository errors honest (FOUND-06). A malformed id maps to not-found. A datastore outage surfaces as a logged 5xx, not an empty result. Today `MongoBaseRepository.get_by_id` catches every exception, prints a traceback to stdout and returns None, so a Mongo outage looks like a 404.

Purpose: Operators can tell an outage from missing data, and clients (Phase 9 mobile retry logic) get a 5xx they can retry.
Output: The guarded Mongo id conversion helper, a catch-all API handler, and end-to-end tests.
</objective>
