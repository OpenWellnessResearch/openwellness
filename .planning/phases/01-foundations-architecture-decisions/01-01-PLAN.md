<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author to CI runner | Code from any contributor (including forks) runs on GitHub-hosted runners |
| Third-party actions to CI runner | Action code fetched at run time executes with the job token |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering / Elevation | `uses:` actions in ci.yml and ios-nightly.yml | high | mitigate | Pin every action to a full commit SHA (verified by the YAML script); top-level `permissions: contents: read` |
| T-01-02 | Information disclosure | Fork PRs reading secrets | high | mitigate | Only the unprivileged `pull_request` trigger; no `secrets.` references (grep gate = 0) |
| T-01-03 | Tampering | Script injection through `github.event.*` in `run:` | medium | mitigate | No event expressions inside `run:` scripts; concurrency uses the PR number only in the `concurrency` key |
| T-01-SC | Tampering | npm / pip / Gradle installs in CI | high | mitigate | Lockfile-only installs (`uv sync --frozen`, `npm ci`, Gradle wrapper with `distributionSha256Sum`); the local Node 22 check uses the Docker Official Image node:22-bookworm-slim with `npm ci` from the lockfile; this plan adds no packages |
</threat_model>
